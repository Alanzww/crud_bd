Como rodar na máquina:

- Clone o repositório:

1. git clone `https://github.com/Alanzww/crud_bd.git`

- Entre na pasta do CRUD:

2. `cd crud_bd/03_CRUD`

- Instale as dependências e inicie (com o MySQL do XAMPP aberto):

3. `npm install`
4. `npm start` ( Pode ser que ele não inicie automaticamente, caso seja necessário use o comando )

- Abra no navegador: `http://localhost:3000`
